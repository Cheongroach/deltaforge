# 怎样使用原始对话记录

本目录用于回查公开对话和工具调用顺序，第一次理解项目请从 [阅读入口](../READING_GUIDE.md) 开始。[TRANSCRIPT.md](TRANSCRIPT.md) 保留历史文字，没有按当前结论重写；当时的计划和判断可能被后续实验修正。

[COVERAGE.json](COVERAGE.json) 记录 original、questions、profiling 三部分的来源、数量和截止。所用云端记录缺少工具结果正文；工具调用索引告诉你“调用了什么”，不能告诉你全部 stdout 或原始运行输出。

因此，核对实验结果要使用 [证据索引](../artifacts/README.md) 指向的 JSON、计时和源码快照。后续训练、失败、发布与文档整理见 [小周报](../progress/WEEKLY_2026-10-25.md)，不要从旧对话中提取某个预期数字当作终态。

公开范围见 [PUBLIC_EXPORT.md](../PUBLIC_EXPORT.md)。本次阅读整理保留 transcript 和覆盖元数据，没有补造缺失记录。
